# DevineLeNombre



Contexte:

Projet réalisé dans le cadre du TP « Utiliser GitHub pour gérer et suivre

un projet informatique ». L'ordinateur choisit un nombre au hasard entre 1 et 100 et le joueur doit

le deviner.



Objectifs:

\- Mettre en pratique Git et GitHub (commits, push, historique)

\- Programmer un jeu simple en Java

\- Documenter un projet avec un README



Fonctionnalités réalisées:

\- Tirage d'un nombre aléatoire entre 1 et 100

\- Saisie des propositions de l'utilisateur

\- Indices « C'est plus grand » / « C'est plus petit »

\- Compteur d'essais

\- Vérification des saisies



Technologies utilisées:

\-PowerShell

\-Git et GitHub

\-Apache NetBeans IDE 31

\-Java: 26.0.2
